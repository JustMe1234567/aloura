# Aloura

Aloura is a responsive luxury fine-jewelry storefront created for the U.S. and Hebrew-speaking markets. The experience includes an editorial homepage, filterable collections, fixed-price product pages, responsive navigation, and an English/Hebrew interface foundation.

## Local development

```bash
npm install
npm run dev
```

Open the local URL shown in the terminal.

## Production build

```bash
npm run build
```

## Design system

See [DESIGN.md](./DESIGN.md) before creating pages or modifying product presentation. It defines Aloura’s brand voice, colors, typography, layout patterns, product-page structure, accessibility requirements, and RTL guidance.
